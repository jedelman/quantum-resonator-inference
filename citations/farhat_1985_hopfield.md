# Optical Implementation of the Hopfield Model
**Source:** Applied Optics (1985)
**DOI:** 10.1364/AO.24.001469
**Authors:** Nabil H. Farhat, Demetri Psaltis, Aluizio Prata, Eung Paek
**Institution:** University of Pennsylvania / Caltech

## Core Claim
First optical neural network: a Hopfield associative memory implemented using a cathode-ray tube (spatial light modulator) and photodetectors. Weights encoded as transmission of a 2D optical mask.

## Historical Significance
The original optical neural network. Established that: (1) matrix-vector multiply can be done optically, (2) feedback (recurrence) is achievable via optoelectronic loop, (3) Hebbian weight encoding in an optical mask is feasible.

## Connection to QRI
The optoelectronic feedback loop in Farhat 1985 is structurally analogous to QRI's inter-layer coupling: detector → re-encode → next layer. The 40-year-old concept validates the general architecture class. QRI replaces the CRT/mask with a holographic resonator and replaces analog electronics with VCSEL drivers.

## Citation Role
Historical anchor. Establishes optical MVM + feedback as a 40-year-old validated concept. QRI is a modern, coherent, resonant realization of the same fundamental idea.
